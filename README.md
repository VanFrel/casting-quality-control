# Категориальные группировки и агрегации данных об отливках в управлении качеством производства литых автомобильных деталей

## И. П. Фрелих, В. Г. Мосин

### Аннотация
Исследуются закономерности возникновения синергетического брака при производстве литых деталей в автомобилестроении на массиве данных из 5 000 отливок. На основе категориальных группировок, комбинаторных агрегаций и энтропийного анализа доказан изоморфизм факторов плавки и партии, а также выявлен скрытый очаг критического брака (до 24,16%) на пересечении сменного фактора и технологической оснастки (Смена 3 × Пресс-форма 9). Изучены физико-металлургические механизмы дефектообразования и предложен превентивный алгоритм CAPA/EWS, обеспечивающий абсолютное снижение уровня брака на 5,5–6,0%.
